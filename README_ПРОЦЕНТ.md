# PROM — ввод процента наценки из консоли

Содержимое архива дополняет предыдущую интеграцию. Запись в магазин отсутствует.

Из корня проекта:

```bash
unzip -o ~/Загрузки/prom_margin_cli.zip -d .
PYTHONPATH=src uv run python предпросмотр_цен_prom.py
```

Программа запросит процент. Для запуска без запроса:

```bash
PYTHONPATH=src uv run python предпросмотр_цен_prom.py --процент 25
```

Поддерживаются целые и дробные значения (`12.5` или `12,5`). Отрицательные и нечисловые значения отклоняются. `0` допустим для проверки без изменения расчётной цены.

Тесты:

```bash
PYTHONPATH=src uv run pytest -q test_источник_prom.py test_процент_консоли.py
```

Обновление касается только сценария запуска и новых тестов. Сам класс `МассовоеОбновлениеЦен` уже принимает параметр `процент`, его изменять не требуется.

# PROM — испытание перехода draft ↔ not_on_display

Этот пакет **добавляет** новый скрипт и тесты, не заменяя существующий эксперимент.

1. Распаковать архив в корне проекта.
2. `uv run ruff check src tests scripts`
3. `uv run mypy src`
4. `uv run pytest -q`
5. Предпросмотр: `uv run python scripts/исследование/проверить_снятие_с_публикации.py --статус not_on_display`
6. После проверки и подтверждения: та же команда с `--отправить`.
7. Убедиться в GET и кабинете, что статус `not_on_display`.
8. Предпросмотр возврата: `uv run python scripts/исследование/проверить_снятие_с_публикации.py --статус draft`
9. После проверки: та же команда с `--отправить`.
10. Убедиться в GET и кабинете, что итоговый статус `draft`.

Не выполняйте повторный POST при неопределённом результате. Сначала установите фактический статус через GET. `deleted` не поддерживается скриптом.

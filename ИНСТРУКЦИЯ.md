# PROM — фиксация API-контракта и единый модуль статусов

Архив добавляет **только три файла**: `src/prom/api/статусы_товаров.py`, `tests/test_статусы_товаров.py`, `docs/СТАТУСЫ_ТОВАРОВ_API.md`. Существующие скрипты не заменяет. Реальные POST не запускает.

Из корня проекта:

```bash
unzip -o ~/Загрузки/PROM_status_contract_module_v1.zip
bash scripts/check.sh
git status --short
git diff --check
git add src/prom/api/статусы_товаров.py tests/test_статусы_товаров.py docs/СТАТУСЫ_ТОВАРОВ_API.md
git diff --cached --check
git diff --cached --stat
git commit -m "Зафиксирован контракт статусов товаров и добавлен модуль операций"
```

Коммит выполняйте **только после успешного Fedora Gate** и просмотра staged diff. Команды не включают автоматическое `git add .`, чтобы случайно не зафиксировать токены, локальные журналы и тестовые данные.

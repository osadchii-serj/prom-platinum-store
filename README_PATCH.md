# PROM — исправление 6 замечаний Ruff

Исправлены SIM102, UP017, I001 (3 файла), UP035. Поведение операций импорта и каталога не менялось.

Установка в корне проекта:

```bash
unzip -o ~/Загрузки/PROM_ruff_six_fixes_v1.zip -d .
uv run ruff check .
uv run mypy src
uv run pytest -q
```

Внимание: полный Ruff/MyPy локально не запускался из-за недоступности зависимостей. ZIP содержит только 4 исправленных файла и эту инструкцию.

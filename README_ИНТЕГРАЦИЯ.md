# PROM — предварительный просмотр наценки 20%

Статус: реализация и локальные тесты. Реальный магазин не проверялся.

Добавлены `src/prom/цены/` и `предпросмотр_цен_prom.py`; существующие файлы проекта не изменены.

Установка: скопировать добавленные файлы в корень проекта с сохранением путей.
Запуск в среде с установленными httpx, rich, python-dotenv и настроенным `PROM_API_TOKEN`:

```bash
PYTHONPATH=src python предпросмотр_цен_prom.py
```

Запросы только `GET /api/v1/products/list`. Записи, смены статуса, публикации нет.

**Ограничение:** алгоритм `last_id` с убывающими ID и размер страницы 100 заложен как проверяемая гипотеза; официальный контракт пагинации не был подтверждён полностью. Если сервер использует другой порядок/пагинацию, компонент прервёт обход, а не выдаст неполный план за полный. Перед рабочим использованием требуется сверить параметры с документацией и ответами API.

Скрипт отображает все изменения в терминале; если каталог большой, вывод может быть длинным. Не публикуйте результаты с персональными данными.

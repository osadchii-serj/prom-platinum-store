# Исследование карточки Prom.ua — этап 1

Скопируйте `src/prom/товары/` в существующий `src/prom/товары/` проекта (создайте папку, если её нет), а файл `tests/test_исследование_карточки.py` — в `tests/`.

Перед запуском убедитесь, что `data/` исключена из Git: `git check-ignore data/исследование_товаров/проверка.json`. Если команда ничего не выводит, добавьте `/data/` в `.gitignore` до запуска.

Запуск из корня проекта:

```bash
./scripts/check.sh
uv run python -m prom.товары.исследование_карточки
```

Запрос: `GET https://my.prom.ua/api/v1/products/list?limit=1`. В реальный магазин ничего не записывается.

Создаются два локальных JSON-файла: исходный ответ API и реестр наблюдаемых путей/типов. Содержимое файлов может включать коммерческую информацию; не публикуйте их в Git или переписке без проверки и обезличивания. Реестр включает поля оболочки ответа API, не только карточки; отделение карточки от оболочки — следующий этап после изучения фактического ответа.

Результаты показывают только наблюдаемые типы. Они не доказывают обязательность, допустимость для записи и ограничения полей.

# PROM — PLATINUM STORE

Локальная среда исследования официального API Prom.ua. Пока **только чтение**; массовые изменения запрещены без отдельного согласования.

## Быстрый старт (Linux)

Требуются Python 3.11+ и `uv`. Из каталога проекта:

```bash
uv sync
uv run pytest
uv run ruff check src tests
uv run python scripts/исследование/диагностика_товаров_prom.py
```

Последняя команда обращается к реальному API **только для чтения** и требует заранее установленной в окружении переменной `PROM_API_TOKEN`. Не вводите токен в файлы проекта или Git.

`uv sync` создаст `.venv` и `uv.lock` при наличии доступа к реестру пакетов. После этого можно выполнить `git add .` и `git commit -m "Создана основа проекта PROM"`. Перед коммитом проверьте `git status` и отсутствие секретов.

## Содержимое

- `PROM_REGULATIONS.md` — исходный регламент.
- `docs/` — ранее зафиксированные результаты исследования и решения.
- `scripts/исследование/` — исходные диагностические скрипты, сохранённые без переработки.
- `src/prom/` — основа нового приложения.
- `tests/` — тесты, не обращающиеся к API.

## Ограничения

Исходные диагностические скрипты перенесены как есть; их ещё предстоит рефакторить, тестировать и объединять. `uv.lock` не включён, так как разрешение зависимостей необходимо выполнить в целевом окружении. Django и PostgreSQL пока не развёрнуты.

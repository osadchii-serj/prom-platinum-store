# PROM — первый модуль

Первый этап новой архитектуры: запуск магазина PLATINUM STORE и проверка доступа к Prom.ua API.

## Установка

В корне существующего репозитория скопируйте файлы этого пакета с сохранением структуры. Не заменяйте `.gitignore`, `PROM_REGULATIONS.md` или `.env`.

В `.env` должна быть переменная `PROM_API_TOKEN` с действующим токеном. Не публикуйте этот файл.

```bash
uv lock
uv sync --group dev
uv run pytest -q
uv run python main.py
```

Проверка подключения выполняется только после выбора команды `1`. Запрос — GET `/api/v1/products/list?limit=5`. Изменения товаров и заказов не производятся. При ответе HTTP 200 проверяется наличие массива `products`.

`platinum-store` — внутренний локальный идентификатор экземпляра, не ID компании Prom.ua.

## Ограничения

Реальная интеграция с аккаунтом ещё не проверялась. Тесты используют HTTPX MockTransport. Ошибки сети и HTTP не раскрывают токен или тело ответа.

## Существующие файлы репозитория

`PROM_REGULATIONS.md`, `.gitignore`, `.env` и `uv.lock` в архив не включены: они уже существуют в вашем проекте. Не перезаписывайте `.env`; после установки выполните `uv lock`, чтобы обновить файл блокировки зависимостей.

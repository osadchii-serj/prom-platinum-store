# PROM — Rich Price Dashboard

Обновление заменяет только два файла, не изменяет API и алгоритм расчёта.

- `src/prom/цены/предпросмотр_цен.py`: панель KPI, сокращённая таблица, фактический процент.
- `предпросмотр_цен_prom.py`: передаёт выбранный пользователем процент в отображение.
- `test_панель_цен.py`: автономные тесты оформления.

Из корня проекта:

```bash
unzip -o ~/Загрузки/prom_price_dashboard.zip -d .
PYTHONPATH=src uv run python предпросмотр_цен_prom.py
PYTHONPATH=src uv run pytest -q test_панель_цен.py
```

Обновление работает только на чтение. Итоги «сумма каталожных цен» — арифметическая сумма цен единичных карточек, не выручка, не прибыль и не оценка складских остатков. Оптовые цены не включены.

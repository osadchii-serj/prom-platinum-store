# Подготовка одной цены

Реализовано: выбор одной карточки из каталога, расчёт, проверка значения по повторному снимку.
Не реализовано: API-запись. Контракт метода редактирования требует отдельной проверки по официальной спецификации https://public-api.docs.prom.ua/ .

Из корня проекта:

```bash
PYTHONPATH=src uv run python подготовить_цену_одной_карточки.py --id 3249449180 --процент 20
PYTHONPATH=src uv run pytest -q test_подготовка_одной_цены.py
```

Это не обновляет магазин. Перед включением записи требуется подтверждённый контракт, журнал, сверка, защита от повторов и отдельное разрешение.

# PROM — план испытаний

Дата: 2026-10-20. Статус: предложено, уточняется по официальному API.

## Этап A. Инвентаризация без записи
1. Зафиксировать весь каталог методов официального Swagger и версии/дату документации.
2. Для каждого метода описать HTTP, путь, параметры, тело, ответ, ошибки, права, лимиты, возможные побочные эффекты.
3. Проверить чтение разрешённых сущностей, не выводить токены и персональные данные.
4. Построить словарь полей и связей товаров, групп, категорий, характеристик, изображений и разновидностей.
5. Сверить данные API с интерфейсом магазина и задокументировать расхождения.
6. Отчёт: проверено / документировано / гипотеза / недоступно / не испытано.

## Этап B. Одна тестовая карточка
Условия входа: явное разрешение владельца/уполномоченного пользователя, проверенные права, безопасная тестовая карточка, исходный снимок данных, план восстановления и запрет воздействия на рабочие товары.
1. Создать (только документированным способом) одну карточку в безопасном статусе.
2. Считать её и сверить все доступные поля.
3. Изменить по одному согласованному полю; сверить запись и повторное чтение.
4. Проверить пустое значение, отсутствие поля, некорректные значения, ограничения и ошибки.
5. Проверить повторный запрос, конкурирующее изменение, тайм-аут и сверку после сбоя.
6. Проверить изменение статуса, скрытие и удаление — лишь после отдельного разрешения и проверки возможности восстановления.
7. Зафиксировать фактические HTTP-ответы без секретов, сравнение до/после и результат восстановления.

## Этап C. Массовая загрузка около 1000 карточек
Условия входа: принятый этап B; согласованы тестовые данные, права, объём, лимиты, резервирование и процедура остановки.
1. Подготовить и валидировать набор из ~1000 записей с устойчивыми идентификаторами.
2. Dry-run и отчёт: создать/обновить/пропустить/конфликт.
3. Испытать небольшую партию и сверить результат.
4. Получить отдельное подтверждение на массовую операцию.
5. Выполнить с контролем статуса, частичных ошибок, повторов, логов и восстановления.
6. Сверить итоговый каталог с ожидаемым набором и подготовить отчёт.

Ни одна операция записи пока не выполнялась.

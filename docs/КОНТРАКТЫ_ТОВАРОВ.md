# Контракты изменения товаров Prom.ua

Источник: https://public-api.docs.prom.ua/documentation/index.yaml

Это описание спецификации, а не подтверждение возможности создания/удаления.
Запросы к магазину НЕ выполнялись.

## POST /products/edit

Назначение: Product editing
Описание: Product list editing.

requestBody.required: True
Формат: application/json
```
$ref: ../schemas/PostProductRequestBody.yaml
Тип: array
Обязательные поля: не указаны
```
Ответы: 200, default

## POST /products/edit_by_external_id

Назначение: Editing products (by external identifier).
Описание: Editing product list (by external identifier).

requestBody.required: True
Формат: application/json
```
$ref: ../schemas/PostProductByExternalIdRequestBody.yaml
Тип: array
Обязательные поля: не указаны
```
Ответы: 200, default

## POST /products/import_file

Назначение: Import of products
Описание: Import of products using xls, csv, xlsx, xml files.

requestBody.required: True
Формат: multipart/form-data
```
$ref: ../schemas/PostProductsImportFileRequestBody.yaml
Тип: object
Обязательные поля: не указаны
- `file`: string
- `data`: object
```
Ответы: 200, default

## POST /products/import_url

Назначение: Import of products
Описание: Import of products using a link to xls, csv, xlsx, xml file.

requestBody.required: True
Формат: application/json
```
$ref: ../schemas/PostProductsImportUrlRequestBody.yaml
Тип: object
Обязательные поля: url
- `url`: string
- `force_update`: boolean
- `only_available`: boolean
- `only_update`: boolean
- `mark_missing_product_as`: string
- `updated_fields`: array
```
Ответы: 200, default

## PUT /products/translation

Назначение: Product translation
Описание: Editing information about the translation of product.

requestBody.required: True
Формат: application/json
```
$ref: ../schemas/PutProductTranslationRequestBody.yaml
Тип: object
Обязательные поля: lang, product_id
- `product_id`: string
- `lang`: string
- `name`: string
- `keywords`: string
- `description`: string
```
Ответы: 200, default

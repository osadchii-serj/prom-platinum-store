# PROM — Контракт товарной карточки: исследование записи

**Статус:** исследование, не утверждённый контракт.  
**Основание:** один реальный ответ `GET /api/v1/products/list?limit=1` от 28.10.2026 и официальный портал https://public-api.docs.prom.ua/.  
**Важное ограничение:** типы GET не доказывают допустимость значений при записи.

## Подтверждённые факты

- Получен один объект товара, 28 полей верхнего уровня.
- Есть вложенные структуры и значения `null`.
- Тестов записи пока не проводилось.
- Полные схемы запросов создания и изменения пока не извлечены из официальной спецификации; их нельзя заменять догадками.

## План экспериментов (пока без отправки)

1. Выбрать **специально созданную тестовую карточку**; не использовать обычную товарную позицию.
2. Зафиксировать ID, исходный полный ответ и контрольную сумму файла; проверить возможность восстановления.
3. Проверить сначала изменение одного безопасного текстового поля и обратное восстановление.
4. Для каждого поля отдельно проверить валидное значение, неверный тип, `null`, отсутствие поля, пустое значение и границы **после подтверждения допустимой операции**.
5. После каждого изменения повторно прочитать карточку и сравнить с ожидаемым состоянием.
6. При неудачном восстановлении прекратить эксперименты и зафиксировать расхождение.

**Запрещено на данном этапе:** массовые операции, изменение существующих коммерческих карточек, создание/удаление без отдельного плана и подтверждения.

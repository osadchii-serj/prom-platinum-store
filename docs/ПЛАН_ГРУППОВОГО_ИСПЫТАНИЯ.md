# План группового испытания двух карточек

**Статус:** реализован только предпросмотр, реальные групповые POST не выполнялись.

- 001: ID `3243922294`, SKU `PROM-TEST-20261022-001`.
- 002: ID `3244158641`, SKU `PROM-TEST-20261022-002`.

Предпросмотр получает оба товара по GET, проверяет закреплённые ID/SKU, сохраняет
исходные статусы и план в `data/групповые_операции/план_двух_карточек.json`.
Перезапись существующего снимка запрещена. Вызов POST отсутствует.

## Маршруты

- `not_on_display → deleted → not_on_display`;
- `draft → deleted → not_on_display → draft`;
- `on_display → draft → deleted → not_on_display → draft → on_display`.

Последний маршрут **составлен из подтверждённых отдельных переходов**, но
**вся цепочка после удаления опубликованной карточки ещё не испытана**.
Наличие плана не означает, что массовый POST безопасен. Перед исполнителем
необходимы журнал, независимая сверка, подтверждение и тест восстановления.

Запуск: `uv run python scripts/предпросмотр_группового_удаления.py --id-002 3244158641`.
